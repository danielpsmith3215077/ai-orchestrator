# DevForge AI — Hero Demo

Minimal Vite + React + TypeScript + Tailwind CSS + Framer Motion scaffold that demonstrates the self-contained `HeroSection` scroll experience.

## Run

```bash
cd devforge-ai
npm install
npm run dev
```

Open the printed local URL (default `http://localhost:5174`) and scroll through the pinned hero.

## Build

```bash
npm run build
```

## Component

`src/components/HeroSection.tsx` is the production deliverable — single file, Tailwind-only styling, Framer Motion `useScroll` / `useTransform` / `useSpring`, no external image/3D assets.
